# Skyward Invexa — project notes

The standing brief in `~/.claude/CLAUDE.md` applies in full. This file records
only what differs, so a future session does not try to rebuild the Vite setup
that was removed on 2026-10-26.

## Stack

**Next.js 16 App Router**, static export. This project is on the Next.js path
alongside `Ai-Nobiloption` and `Ceravindo-Platform`.

```
app/
  layout.tsx            root shell: fonts, site metadata, header/footer, GA, site schema
  globals.css           the whole design system, one file (Tailwind v4 + @theme tokens)
  page.tsx              home
  <route>/page.tsx      one directory per route
  not-found.tsx         becomes 404.html
  sitemap.ts            generated from src/data, not hand-maintained
src/
  components/           all UI
  data/                 site, content, pages, faq, countries, about
  lib/                  metadata mapping, phone helpers, lead relay, chart data
  views/                page components (NOT src/pages: see below)
public/                 flags, images, og-image, robots.txt, gtag-init.js
```

`next.config.mjs` sets `output: 'export'` and `trailingSlash: false`. Routes
build to `out/<route>.html`, so canonical URLs stay slash-free and `/about` is
served straight from `about.html`. `out/404.html` gives an unknown path a real
404 status.

Build with `npm run build`. Output is `out/`, not `dist/`.

## Rules that are easy to break here

- **`src/views`, never `src/pages`.** Next treats a `pages/` directory as the
  Pages Router and refuses to build when `app/` exists too. The page components
  live in `src/views` for that reason alone.
- **`'use client'` is required** on anything with a hook: `Navbar`,
  `EnquiryForm`, `PhoneField`, `Accordion`, `MarketTicker`, `Sparkline`.
  Everything else is a server component and must stay one.
- **Metadata comes from `src/lib/metadata.ts`**, which maps a page's title,
  description and path onto Next's Metadata API. Each route's `page.tsx`
  exports it; static pages re-export theirs from `src/views/<Name>.tsx`. Do not
  hand-write head tags in a page.
- **Noindex routes carry no canonical.** `pageMetadata()` omits it when
  `noindex` is set. `app/not-found.tsx` also drops `robots`, because Next adds
  its own and two tags end up in the HTML.
- **JSON-LD is rendered, not injected.** `JsonLd` emits a `<script>` into the
  document so the schema is in the prerendered HTML. The Vite build appended it
  after hydration, which a crawler without JavaScript never saw.
- **Fonts go through `next/font/google`**, which downloads at build time and
  serves the WOFF2 files from this domain. That is why the CSP no longer lists
  `fonts.googleapis.com` and why `out/index.html` carries no Google Fonts link.
- **Analytics lives in `app/layout.tsx`**, with the init still in
  `public/gtag-init.js` so the CSP can keep `script-src` without
  `'unsafe-inline'`.
- **`vercel.json` has no rewrites.** Static export emits one file per route, so
  a rewrite to `/index.html` would 404. Headers only.
- **`app/sitemap.ts` needs `dynamic = 'force-static'`** or the export build
  refuses to collect it.
- **`AGENTS.md` at the repo root is generated by `next dev`.** It is
  gitignored; removing it only re-creates it.

## Verifying

More than one dev server is often listening on this machine, and a port serving
another project returns 200 and looks fine. Confirm the server is serving *this*
site before testing:

```bash
curl -s http://localhost:<port>/ | grep -o '<title>[^<]*'
```

It must say "Skyward Invexa". Port 4180 is Ceravindo on this machine.

```bash
npm run build
npm run check:ssg          # files, head, schema, sitemap, assets. No browser.
npm run serve              # serves out/ on 4180 or the next free port
npm run check:meta         # Chrome, needs a server. SHOT_BASE overrides the port.
npm run check:layout       # panel clearance at four widths
npm run check:flags
npm run audit
```

`npm run check:ssg` replaces the React Router smoke test the Vite build used.
`next start` does not exist with `output: 'export'`, so the browser checks run
against `npm run serve` or `npm run dev`.
